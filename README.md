## 1. Executive Summary

**Cindevra** is a specialized, sovereign operating system and clinical management platform built for licensed psilocybin service centers, facilitators, and ketamine clinics administering psychedelic-assisted therapies and neuro-regenerative treatments.

It handles everything a licensed operation needs to run safely and in good standing with state and federal regulators — from session protocols and state-mandated custody logs to live vital-sign monitoring during active journeys — while ensuring through zero-knowledge mathematical cryptography that a patient's deeply personal psychological experience remains strictly private and under their sole custody.

## 2. Why Cindevra Was Built

As psychedelic-assisted care transitions from underground and clinical-trial environments into regulated, licensed operations, operators face two conflicting pressures:

1. **Strict Regulatory Compliance:**
   - **Oregon Health Authority / Oregon Psilocybin Services (OPS):** License verification, lot tracking, dual-facilitator sign-offs, and state Cannabis Tracking System (CTS) manifests.
   - **Colorado Natural Medicine Health Act (NMHA):** Facilitator ratios, state compliance reporting, and sanctuary administration.
   - **Ketamine Clinics:** DEA Schedule III standards, milligram-accurate perpetual dispensing logs, and medical board compliance.
2. **Intense Privacy Vulnerability:**
   - During a psychedelic journey, a person shares their deepest traumas, subconscious thoughts, and emotional memories.
   - If traditional clinic software or commercial AI systems log these experiences to unprotected third-party clouds, that data can be subpoenaed, breached, or monetized.

**Cindevra resolves this tension:** It provides operators with the tools to satisfy their governing bodies, while utilizing zero-knowledge cryptographic vaults so participants own their journey telemetry and notes completely — nobody can sell, scrape, or access it without explicit, patient-held cryptographic permission.

## 3. Core Architectural Layers (The Tree Matrix)

Cindevra is engineered as a 5-layer living botanical architecture:

```
                  [ CANOPY LAYER ]
             Patient & Family Integration
         (Decentralized Key, Micro-Dosing, Circle)

                  [ BRANCH LAYER ]
             Sanctuary Clinical Operations
         (Vault Custody, Dual-Attestation, Billing)
                         │
                  [ TRUNK LAYER ]
            Evidence-Informed Clinical Protocols
         (Johns Hopkins, NYU, MAPS-derived, Forking)
                         │
                   [ ROOT LAYER ]
             Sovereign Cryptographic Foundation
         (ZK Proofs, 42 CFR Pt 2, Self-Destruct Shredder)
```

### Layer 1: Root Layer (Sovereign Cryptographic Foundation)
- **Zero-Knowledge Proofs (ZKP):** Verify patient intake eligibility and contraindication clearances without decrypting underlying psychiatric histories.
- **Cryptographic Key Shredder ("Right-to-Be-Forgotten"):** Instant, permanent destruction of decryption keys on patient request, rendering historical inner-experience logs cryptographically unrecoverable against subpoenas or breaches.
- **42 CFR Part 2 Granular Consent:** Segmented disclosure authorizations separating medical vitals from psychotherapy notes and substance use disorder (SUD) data.
- **Tamper-Evident Audit Chain:** Cryptographically linked SHA-256 hash ledger adhering to 21 CFR Part 11 standards.

### Layer 2: Trunk Layer (Clinical Protocols & Knowledge Base)
- **Evidence-Informed Protocols:** Validated templates adapted from published frameworks (Johns Hopkins TRD/Existential Distress, NYU psilocybin protocols, MAPS-derived MDMA structures).
- **Protocol Forking Engine:** Service centers can fork standardized protocols into specialized, cohort-specific variants with micro-milligram adjustments.
- **Clinical Scales Integration:** Longitudinal MEQ-30 (Mystical Experience Questionnaire), PHQ-9, and GAD-7 assessment tracking.
- **Pharmacological Interaction Matrix:** Real-time drug-drug contraindication engine evaluating SSRIs, SNRIs, MAOIs, and lithium against serotonergic substances.

### Layer 3: Branch Layer (Sanctuary Operations & Substance Vault)
- **Substance Vault & Perpetual Custody Ledger:**
  - *Psilocybin (Oregon OPS / Colorado NMHA):* Lot tracking, state transfer manifests, two-person witness sign-offs, and dosage accountability.
  - *Ketamine (Medical Clinics):* DEA Schedule III milligram-accurate dispensing balances and dual-custodian reconciliation.
  - *MDMA (FDA IND / Investigational):* Pre-configured regulatory architecture ready for federal scheduling transitions.
- **Regulated Waste Logging:** Witnessed chemical neutralization and destruction accounting with immutable dual signatures.
- **Payment Transparency & Billing:**
  - Full support for **cash-pay** realities (dominant model in state-licensed psilocybin centers).
  - Out-of-network superbill generation with optional AMA CPT Category III coding (`0820T` lead QHP, `+0821T` co-therapist, `+0822T` clinical chaperone) for medical ketamine clinics.

### Layer 4: Canopy Layer (Patient Sovereignty & Integration)
- **Self-Custody Portal:** Direct patient key holding; patients choose which data elements are shared with their care team.
- **Micro-Dosing & Integration Journals:** Multi-week neuroplastic window consolidation tracks somatic landing, boundary negotiation, and flourishing indices.
- **Integration Circle Coordination:** Peer circles and family system dialogue scheduling under end-to-end encryption.

### Layer 5: Mycorrhizal Layer (Federated Research & REMS)
- **Decentralized Research Commons:** Centers opt in to contribute anonymized outcomes to research institutions without exposing identifiable patient journeys.
- **Automated REMS & Regulatory Reporting:** One-click generation of adverse-event dossiers and state licensing quarterly reports.

## 4. Live Journey Cockpit (`/live-journey`)

During active administration sessions, facilitators operate a dedicated, real-time safety dashboard:
- **Biomarker Telemetry:** Real-time heart rate (HR), blood pressure (BP), and heart rate variability (HRV) telemetry stream with threshold alerts.
- **Somatic Log Ledger:** Facilitators timestamp verbal check-ins, participant touch consent states, and grounding interventions.
- **Acoustic Environment Control:** Built-in 432 Hz grounding synthesizer and theta-wave harmonic drone generator for active session stabilization.
- **Rapid Rescue Protocol Modal:** Quick-action guidance for acute psychological distress, hypertensive spikes, or medical escalation (including 911 EMS / on-call physician paging).

## 7. Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
Clone the repository and install dependencies:
```bash
npm install
```

### Development Server
Run the local development server:
```bash
npm run dev
```
The application will launch at `http://localhost:3000`.

### Linting & Type Checking
Verify all TypeScript interfaces and compile rules:
```bash
npm run lint
```

### Production Build
Build the minified production bundle:
```bash
npm run build
```

## 8. Regulatory & Legal Clarifications

- **Psilocybin (Oregon / Colorado):** Cindevra is designed for state-licensed service centers, facilitators, and testing labs operating pursuant to Oregon Ballot Measure 109 (ORS 475A) and Colorado Proposition 122 (NMHA). Psilocybin remains a Schedule I controlled substance under federal law; state licensing does not confer federal DEA registration.
- **Ketamine:** Ketamine is an FDA-approved DEA Schedule III dissociative anesthetic. In medical clinic settings, Cindevra provides DEA-compliant chain-of-custody tracking and off-label psychotherapy documentation.
- **MDMA:** MDMA remains a DEA Schedule I substance. Cindevra's MDMA architecture is designed for FDA-approved expanded access / IND investigational clinical trial protocols, pre-positioned for future scheduling transitions.
- **Billing Transparency:** Psilocybin care in state-regulated models is currently cash-pay. Insurance reimbursement is not available for non-FDA-approved substances. Cindevra provides optional superbill and CPT Category III coding solely for medical settings (ketamine) or research trials.
